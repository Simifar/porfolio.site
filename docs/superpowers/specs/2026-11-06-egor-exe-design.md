# EGOR.EXE — A Tech World

The user-provided handoff is the approved specification. Audience: employers seeking IT Support / PC Hardware staff. Keep all factual content, EN/RU, themes, PDF resumes, HashRouter, public URL and static cases.

## Direction
An original forest workshop: warm ivory typography, deep green surfaces, lime highlights, cyan diagnostics and brass accents. Original isometric SVG workshop on a grass-and-earth block island, without WebGL. Quiet grid and pixel corners; meaningful HUD labels. Modern readable IBM Plex body with locally hosted, licensed pixel display face supporting Cyrillic.

## Architecture
Preserve routing, case data, metadata, static generation, command menu and contact behavior. Replace Hero, enrich existing Sections and add focused Inventory / Workstation / Highlights components. A shared workshop SVG supports illustrated hero and selectable technical objects with equivalent native buttons and an ordinary detail panel. Keep all information available outside interaction, via profile and inventory text mode.

## Interaction
Inventory: eight native toggle buttons, explicit experience status, selected detail, keyboard and tap, optional complete text list. Workstation: five labeled native controls linked to a detail region; object highlight follows selection. No game gate, scores, sound, invented facts or simulated terminal.

## Responsive / motion
320/390: stacked hero, actions before scene, readable touch controls and mobile inventory. 768: stacked or compact grids. 1440: composed editorial hero and two-column workshop. Static illustrations need no network requests. Reduced motion disables decorative movement. Theme tokens cover all home and case states.

## Alternatives considered
WebGL adds payload and recovery complexity with no meaningful interaction benefit. A decorative corporate page would miss the brief. SVG plus semantic HTML gives a distinctive lightweight workshop with accessible controls.
