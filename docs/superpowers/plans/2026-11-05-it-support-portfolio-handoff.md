# IT support portfolio: complete implementation handoff

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Полностью реализовать пять согласованных направлений улучшения портфолио Егора Матафонова для работы с компьютерами, технической поддержки и удалённой технической поддержки; довести до проверенного результата, готового к публикации.

**Architecture:** Сохранить существующие React/Vite, HashRouter, двуязычность и темы. Данные о человеке и проектах остаются общими для интерфейса и статических кейсов. Исправлять существующий сайт без полного редизайна и без нового широкого аудита.

**Tech Stack:** React 18, TypeScript, Vite, Tailwind CSS 4, React Router, Playwright, axe, Lighthouse CI. Версии сверить с актуальным package-lock.json.

**Spec:** Этот документ фиксирует задание пользователя и требования из проведенного аудита. Пользователь поручил: «Сделай handoff к новому чату для полноценной реализации всех 5 пунктов от и до». Требуется реализация, а не повторный отчёт или предложение начать.
